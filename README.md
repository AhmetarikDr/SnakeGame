# SnakeGame
Finals for game programming 2

It's the basic snake game, you move with W,A,S,D and try to eat apples.
If you hit a wall or yourself you die.
Snake get's faster and longer the more it eats.
After getting 200 points (eating 20 apples), next level starts. There are three levels.
If you beat level three you win.

You can use Space button as Accept in menu or win screen.
You can press the play and quit buttons with your mouse.
You can press Escape to quit the game.

Have fun!
